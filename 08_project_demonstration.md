# Phase 8 - Project Demonstration

## Demonstration Objective

Demonstrate that a standard laptop procurement request can be processed
through the automated workflow from submission to completion.

## Demo Preparation

Before the demonstration: - Ensure the ServiceNow instance is
available. - Verify the catalog item. - Verify the Flow Designer flow is
active. - Verify approver and assignment groups. - Prepare a test
requester. - Prepare a test laptop request. - Confirm notifications are
configured.

## Demonstration Script

### Step 1 - Submit Request

Show the Standard Laptop Procurement catalog item and enter sample
information.

### Step 2 - Submit

Submit the request and show the generated request/requested item.

### Step 3 - Approval

Open the approval record as the approver and approve the request.

### Step 4 - Automated Fulfillment

Show that Flow Designer creates the fulfillment/procurement task
automatically.

### Step 5 - Assignment

Show the task assigned to the appropriate IT/procurement group.

### Step 6 - Notification

Show the notification received by the requester or approver.

### Step 7 - Fulfillment

Complete the laptop fulfillment task and update the relevant status.

### Step 8 - Completion

Show that the request reaches the completed state and that the requester
receives a completion notification.

## Rejection Demo

Optionally submit another request and reject it during approval.
Demonstrate that fulfillment is not started and the requester is
notified.

## Final Points to Explain

-   What manual work was reduced?
-   Which steps are automated?
-   How approval is controlled?
-   How requests are tracked?
-   How exceptions are handled?
-   How the solution can be extended to other IT equipment.

## Expected Demo Result

The audience should be able to see the complete lifecycle of a standard
laptop procurement request and understand how ServiceNow Flow Designer
automates the process.
