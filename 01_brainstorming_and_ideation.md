# Phase 1 - Brainstorming & Ideation

## Project Name

**Streamlining IT Procurement - Automated Standard Laptop Orders**

## Problem Statement

Traditional IT procurement can involve emails, spreadsheets, manual
approvals, repeated data entry, and limited visibility into order
status. These activities can delay laptop delivery and make it difficult
for IT and procurement teams to track requests.

## Proposed Idea

Create an automated ServiceNow procurement workflow for standard laptop
orders. A requester submits a standardized laptop request. The system
validates the request, obtains the required approval, creates
fulfillment/procurement tasks, updates status, and sends notifications
automatically.

## Objectives

-   Reduce manual procurement activities.
-   Standardize laptop requests.
-   Automate approval routing.
-   Improve request tracking.
-   Reduce processing delays.
-   Provide notifications at important stages.
-   Maintain an auditable request history.

## Initial Workflow Idea

Requester -\> Laptop Request -\> Validation -\> Manager Approval -\>
Procurement/Fulfillment -\> Delivery -\> Completion Notification

## Key Users

-   Employee / Requester
-   Manager / Approver
-   IT Service Desk
-   Procurement Team
-   Asset Management Team
-   IT Administrator

## Expected Benefits

-   Faster request processing
-   Fewer data-entry errors
-   Consistent approval process
-   Better visibility
-   Centralized records
-   Improved user experience

## Brainstorming Questions

1.  What information should the requester provide?
2.  Who should approve a laptop request?
3.  What conditions require additional approval?
4.  Which tasks should be automated?
5.  What notifications are required?
6.  How should exceptions be handled?
7.  What reports should management see?

## Initial Success Criteria

A standard laptop request should be submitted, approved, fulfilled,
tracked, and closed with minimum manual intervention.
