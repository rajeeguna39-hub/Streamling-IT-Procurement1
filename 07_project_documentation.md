# Phase 7 - Project Documentation

## 1. Project Summary

The Streamlining IT Procurement project automates the standard laptop
ordering process using ServiceNow and Flow Designer.

## 2. User Process

1.  Employee opens the Standard Laptop Procurement catalog item.
2.  Employee enters the required information.
3.  Employee submits the request.
4.  The system validates the request.
5.  The manager receives an approval request.
6.  Approved requests move to fulfillment.
7.  IT/procurement completes the required task.
8.  The requester receives status notifications.
9.  The request is completed and retained for tracking.

## 3. Administrator Configuration

Document: - Catalog item name - Variables - Flow name - Trigger -
Actions - Decision conditions - Approval rules - Assignment groups -
Notifications - Roles - Tables/records used

## 4. Flow Documentation

Maintain a step-by-step description of every Flow Designer action and
decision.

## 5. Notification Documentation

For every notification document: - Notification name - Trigger
condition - Recipient - Subject - Message body - Dynamic fields used

## 6. Security Documentation

Document the roles required to: - Submit requests - Approve requests -
Process fulfillment tasks - View procurement information - Administer
the solution

## 7. Maintenance

Future administrators should review the flow, approval rules, groups,
notifications, and catalog variables whenever procurement policies
change.

## 8. User Guide

The final user guide should include screenshots of: - Catalog item -
Request submission - Approval - Fulfillment task - Completed request -
Notifications
